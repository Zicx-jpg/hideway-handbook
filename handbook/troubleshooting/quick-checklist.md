# Quick checklist

Go top to bottom and stop at the first thing that is not right. Each step links to the page with the fix.

1. **Hardware.** The game PC is on, the DMA card is seated, and its USB cable is in a motherboard port on the overlay PC. See [DMA card](dma-card.md).
2. **Start-up and license.** The launcher runs as administrator, your key is accepted and the clock is right. See [Start-up and license](startup-and-license.md).
3. **READY CHECK.** Turn on Misc > Debug > Show debug page, open Debug and read the **Next:** line. See [Is everything connected?](../getting-started/ready-check.md).
4. **You are in a match.** The lobby has nobody to draw, and "waiting" rows are normal there.
5. **OFFSET HEALTH has no red line.** A red World, Camera or Players line usually means the game was patched. See [After a Fortnite update](../guides/after-a-fortnite-update.md).
6. **DATA HEALTH shows LIVE for what you use.** Names, Team ID and Skeleton should be LIVE in a match. Health is normally partial. See [Health and shield bars](health-and-data.md).
7. **Input device**, only if you use aim or trigger: it is connected in the top bar and **Test move (+/-60)** moves the mouse. See [Connect an input device](../guides/input-device.md).
