# Hotkeys

Every key can be rebound. Click the box next to a key option, then press the key or mouse button you want. Click the box a second time to use **Mouse 1**. **Right-click** the box to clear it. **Config > KEYBINDS** lists every key in one place with a **Conflicts** line that should say *none*.

| Key | Default | What it does | Where |
|---|---|---|---|
| **Menu key** | Insert | Open / close the menu | Misc > KEYS |
| **Exit key** | End | Close Hideway | Misc > KEYS |
| **Panic key** | not set | Instantly hide everything and stop reading the game. Press again to resume | Misc > KEYS |
| **Master toggle key** | not set | Turn all cheat features on or off without closing the menu | Misc > KEYS |
| **Next config key** | not set | Switch to the next config | Misc > KEYS |
| **Previous config key** | not set | Switch to the previous config | Misc > KEYS |
| **Aim key** | Mouse 2 | Hold to aim | Aimbot |
| **Trigger key** | Mouse 5 | Activates the triggerbot in *Hold key* mode | Triggerbot |
| **Radar toggle key** | not set | Show / hide the radar | Radar |
| **Radar enlarge key** | not set | Make the radar bigger while toggled | Radar |
| **Fuser toggle key** | not set | Open / close the fuser window | Visuals > HUD |

{% hint style="info" %}
With **Read game-PC mouse buttons** on (Misc > ENGINE), mouse keys are read from the **game PC's** mouse through your input device. Hideway's own clicks are ignored.
{% endhint %}

## Tips

* Pick a **Panic key** you can reach with one finger; it is your fastest way to hide everything.
* If a key does nothing, check **Config > KEYBINDS > Conflicts**: two options on the same key can shadow each other.
* A key that is a mouse button works only if the overlay PC (or the device) actually sees that button.
